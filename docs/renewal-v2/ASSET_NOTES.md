# 제품 이미지 자산 주의사항

- 원래 `*-03.png`, `*-07.png`, `*-24.png` 등 일부 자산은 배경+앞 패널이 합쳐진 Figma 전체 그래픽이다. 그 위에 같은 앞 패널을 다시 얹으면 중복된다.
- `product-layers.json`은 실제 피그마에서 분리한 배경·앞 패널·기준 좌표와 태그를 제공한다. Desktop/Mobile을 각각 사용한다.
- 새 `*-background.png`에는 앞 패널과 중복 라벨을 제거했고, `*-layer.png`에는 패널 뷰포트만 담았다. 패널 그림자는 제거했으므로 CSS에서 한 번만 적용한다.
- 움직임은 앞 패널에만 적용한다. Reduced motion에서는 최종 정지 구도를 바로 표시한다. 합성본만 사용하는 경우 이미지 속 태그와 별도 HTML 태그를 중복 렌더링하지 않는다.
- 원본 Figma 화면·문구·노드는 수정하지 않았고 임시 복제본만 추출 후 제거했다.
- `orbit-*-section.png`는 Figma 원본 전체 화면에서 잘라낸 참고 이미지이며 웹의 텍스트/레이아웃을 통째로 이미지로 대체하는 용도가 아니다.
